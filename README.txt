TAKSH PWA DEMO

Files:
- index.html: TAKSH V2 interface
- manifest.webmanifest: installable app metadata
- sw.js: basic offline app-shell cache

Important:
This is still a local/demo app. It does NOT provide real accounts, server-side
storage, cross-device sync, moderation, or public posts. Browser local file
opening may not enable PWA installation; the files must be hosted over HTTPS.

Next step:
Publish these files to a static HTTPS host (for example GitHub Pages). Then
open the published HTTPS URL in Android Chrome and use menu > Add to Home screen
(or Install app, if offered).

Do not add passwords, OTPs, or private information to this demo.
